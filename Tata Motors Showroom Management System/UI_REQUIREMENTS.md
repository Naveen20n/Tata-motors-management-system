## Responsive Design
Use Bootstrap 5:
- Extra small: 1 column
- Small: 2 columns
- Medium: 3 columns
- Large: 4 columns
- Extra large: 4 columns

## UI Rules
1. Use Bootstrap 5.
2. Do not use Tailwind.
3. Reuse components.
4. Use accessible labels.
5. Provide loading, empty and error states.
6. Keep forms validated.
7. Ensure keyboard accessibility.
